VPN 用戶端安裝說明

發布單位：資訊部 網路組　｜　最後更新：2026/11/02

適用對象

需要從公司外部（在家、出差）存取內部系統的同仁。請於 2026/11/30 前完成新版用戶端安裝，舊版用戶端將於 12 月停止連線。

步驟 1：下載用戶端

請至「軟體中心」搜尋 Oiia VPN Client 5.2 並點選安裝。若找不到，請洽 IT 服務台（分機 1234）。

步驟 2：安裝並重新開機

依照安裝精靈點選「下一步」即可，安裝完成後請重新開機一次。

步驟 3：匯入連線設定

開啟 VPN 用戶端，點選 設定 → 匯入，貼上以下內容：

# Oiia VPN 用戶端設定（2026/11 版）
# 共用帳號，請勿外流
server   = vpn.oiia.example
port     = 443
protocol = ssl
username = vpn.user
password = ZmxhZ3syMDI2X0lUX1NoYXJpbmcjNH0=   ; 已加密，請安心使用

🔒 為保障資訊安全，設定檔中的密碼已經過加密處理，請直接匯入即可，無須另外輸入密碼。

步驟 4：連線測試

  1. 點選 連線，狀態顯示「已連線」即完成。
  2. 開啟瀏覽器確認可以進入內部系統。
  3. 若出現「驗證失敗」，請截圖並至新版 IT 報修提出申請。
